Inference

Bootstrapping, tests, and how confidence is computed

These pages quantify uncertainty on the incremental MMM so a mix recommendation is not a single number. Residual bootstrap, block bootstrap, permutation, and classical t-tests are shown together because they answer the same stakeholder question in different languages.

Pipeline Point model Residual bootstrap Block bootstrap Percentile intervals Tests Ship / Watch / Kill Production

Solving approach

  1. Fit the incremental MMM (adstock + Hill spend, log price, season, holiday) by OLS.
  2. Draw B residual-bootstrap coefficient vectors (default 280).
  3. Draw B moving-block bootstrap coefficient vectors (block length 8 weeks).
  4. Map each draw to iROAS at mean spend and to the profit gap versus a last-touch mix.
  5. Report 90% and 80% percentile intervals. Compare interval widths across the two bootstraps.
  6. One-sided and two-sided bootstrap p-values, plus a permutation test that breaks the price–sales link.
  7. Translate intervals into Ship / Watch / Kill so the recommendation pack is not a wall of p-values.

Point model

Y = Xθ + ε
X = [1, season, holiday, log(P/100), x̃_TV, x̃_Social, x̃_Search, x̃_Email]
θ̂ = (X'X)^{−1} X'Y

Classical (shown only as a foil):
  se_j = s √(X'X)⁻¹_jj
  t_j  = θ̂_j / se_j  ~ t_{n−k}   under iid normal ε
  95% CI = θ̂_j ± t_{0.975, n−k} se_j

Weekly media residuals are almost never iid. That is why the bootstrap is the number we brief, and the t-test is the “what a textbook would have said” column.

Residual bootstrap

Fit:  Ŷ = Xθ̂,   e = Y − Ŷ
Draw: e* ~ sample(e) with replacement
      Y* = Ŷ + e*
      θ* = (X'X)⁻¹ X'Y*

Repeat B times. This keeps the design X fixed and treats
the residual cloud as the sampling distribution of noise.

Moving-block bootstrap

Split the n weeks into blocks of length L (default 8).
Draw blocks with replacement until n rows are filled.
Refit OLS on the concatenated blocks.

If leftover autocorrelation or holiday clusters matter,
Var*(θ_block) > Var*(θ_residual).

We do not use a naive iid pairs bootstrap on weeks: that would break adstock structure already baked into x̃. Residual and block are the two honest options once transforms are treated as known.

Percentile intervals and iROAS

90% CI:  [Q_0.05(θ*), Q_0.95(θ*)]
80% CI:  [Q_0.10(θ*), Q_0.90(θ*)]

iROAS_c* = θ*_c * T'(s̄_c)
T'(s)    = [K / (K + s/(1−θ))²] / (1−θ)

Profit gap* = π(even mix; θ*) − π(last-touch mix; θ*)

Ship / Watch / Kill

Ship  if Q_0.05(β*) > 0  and  Q_0.10(iROAS*) > 1
Kill  if Q_0.95(β*) < 0  or   Q_0.90(iROAS*) < 1
Watch otherwise

These are decision rules, not p-value theater. Watch means “keep the lock and go get a geo test,” not “the model failed.” Kill means do not ask for more budget on that channel from this evidence.

How to run this on a real model

  1. Treat adstock θ and Hill K as fixed for the inner OLS, or nest a thinner bootstrap around a grid of (θ, K) if those were estimated.
  2. Prefer block or circular bootstrap on weeks. Residual bootstrap is the speed option when DW is near 2.
  3. B = 1,000 for a board pack. B = 280 is enough to see the shape on this studio.
  4. Brief the interval and the gate, not the p-value alone. Finance can read “TV iROAS 1.4 to 2.1” without a statistics lesson.
  5. If classical p < 0.001 and bootstrap p is 0.08, believe the bootstrap. Weekly MMM residuals are clustered.
  6. Do not ship a price move unless the permutation test and the CI agree.
